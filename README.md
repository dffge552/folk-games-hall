# 🎲 民間棋類大廳

> 保存即將失傳的傳統棋藝 · 讓老一輩的智慧重現於數位世界

---

## 📖 簡介

圍棋、象棋、國際象棋人人皆知，然而在世界上，還流傳著許多「叫不出名字，許多阿公阿嬤卻都會下」的棋。

奧雀雀棋、靶棋、車輪棋……這些棋藝曾是街頭巷尾的日常娛樂。然而隨著長輩凋零，這些民間智慧正面臨失傳的危機。

**民間棋類大廳** 蒐集了 **18 種世界傳統民間棋類**，將其數位化，讓任何人隨時都能體驗這些老一輩的智慧結晶。

保存它們，不只是保存遊戲規則，更是保存一個時代的溫度。

## 🎯 功能特色

- **多種對戰模式**：雙人對戰、人機對戰（AI 採用 Alpha-Beta 或完美查表）
- **AI 難度調整**：簡單／普通／困難，可調整思考深度
- **AI 分析功能**：顯示最佳走法建議與局面評估
- **編輯局面**：自由擺放棋子，自訂開局
- **悔棋功能**：可退回上一步（人機模式自動退兩步）
- **棋譜記錄**：自動記錄對局過程
- **完整規則說明**：每種棋皆有詳細的遊戲規則彈窗
