🎲 五行棋 玩法說明

🎯 遊戲目標

將對手的棋子全部吃掉，或讓對手無合法走法即獲勝。

♟️ 棋子與陣營

  • 黑方（先手）：4枚，位於上方四個位置
  • 白方（後手）：4枚，位於下方四個位置

🏃 移動規則

  • 棋子可沿著棋盤上的連線移動，每次可走1~4步（不可中途改變方向）。
  • 移動路徑上不可穿越己方棋子。
  • 移動路徑上不可穿越對方棋子，除非：移動恰好4步並停在對方棋子的位置上，即為「吃掉」該棋子。
  • 被吃掉的棋子從棋盤上移除。

🎨 操作提示

  • 點擊己方棋子選取，會顯示可走到的位置（高亮圓圈）。
  • 再點擊高亮位置即可移動/吃子。
  • 吃子後該位置即空出。

⚡ 特殊說明

  • 棋子帶有五行字樣（金木水火土），僅為美觀，不影響規則。
  • 棋盤中央四條斜線連接了各個位置。

🤖 AI 對戰

  • AI 採用完美強解資料庫（wuxingqi.bin），所有局面均為必勝/必敗/和棋標記。
  • 可選擇執黑（先手）或執白（後手）。
  • 點擊「AI分析」模式可瀏覽所有合法走法的勝負結果。

✏️ 編輯模式

  • 可自由擺放棋子，自訂開局。
  • 編輯完成後點「確認局面」即可開始對弈。

💾 資料庫需求

  • 本遊戲需要 wuxingqi.bin 強解資料庫檔案方可使用AI分析功能。
  • 請確保檔案與此 HTML 位於同一目錄，並透過 HTTP Server 開啟。
